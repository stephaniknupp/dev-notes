Jamstack vem de JavaScript, APIs e Markup. O site é pré-renderizado no build e entregue por uma CDN.

## Fluxo de CI/CD

1. Faço um commit no GitHub.
2. O build é disparado no GitHub Actions.
3. Se o build passar, o deploy no GitHub Pages é automático.
