# dev-notes

O Dev Notes é um blog de estudos feito em Gatsby, onde vou registrar meus aprendizados sobre programação e desenvolvimento de software.

A ideia é ter um espaço para documentar o que aprendi em cada aula, curso ou estudo, organizando tudo em notas que posso consultar e revisar depois.

A página inicial lista as notas mais recentes, e cada nota é um arquivo Markdown que gera sua própria página.

As notas ficam em `content/notes`. Cada arquivo gera uma página em `/notes/slug`.

- Site: https://stephaniknupp.github.io/dev-notes/
- Repositório: https://github.com/stephaniknupp/dev-notes

Para rodar o projeto:

```bash
npm install
npm run develop
```
